# 🏨 Hotel Dhanlakshmi – Maharashtrian Restaurant Management System

A modern full-stack restaurant management system designed for authentic Maharashtrian cuisine. It provides a smooth customer ordering experience and a powerful admin dashboard for restaurant operations.

## 🌟 Key Features

### 🍽️ Customer
- Browse authentic Maharashtrian menu  
- Guest checkout (no forced login)  
- COD & online payments (Razorpay)  
- Real-time order status  
- Best sellers of the day  
- Discount coupons  
- Fully mobile responsive  
- English + Marathi support  

### 👨‍💼 Admin
- Secure admin login  
- Dashboard for orders, products & revenue  
- Real-time order management  
- Coupon creation & tracking  
- Best sellers & revenue analytics  
- Restaurant settings (info, hours, payments)  

## 🔧 Tech Stack
- **Frontend**: React + Vite + Tailwind  
- **Backend**: Node.js + Express  
- **Database**: MongoDB  
- **Payments**: Razorpay  
- **Notifications**: WhatsApp API  
- **Security**: bcrypt, CORS, rate limiting  

## 🚀 Setup Overview
- Install client & server dependencies  
- Add environment variables for database, payments, and API keys  
- Start backend and frontend in development mode  

## 📱 User Flow
**Customer:** Menu → Cart → Checkout → Payment → Track Order  
**Admin:** Login → Dashboard → Manage Orders → Update Menu → Coupons → Settings  

## 🔒 Security Highlights
- Password hashing  
- API key protected admin routes  
- Input validation & rate limiting  
- Environment-based config  

## 📊 Business Capabilities
- Daily/weekly/monthly revenue stats  
- Discount usage insights  
- Best sellers with auto-tracking  
- Order lifecycle management  

## 🌐 Deployment
- Client: Netlify  
- Server: Render  
- Database: MongoDB Atlas
